# Music

The game ships with **procedurally generated music** (see `src/game/music.ts`)
so there are no licensing concerns at all.

If you prefer real tracks, drop loops here and set `USE_MUSIC_FILES = true`:

| File | Used for |
| --- | --- |
| `menu.mp3` | main menu |
| `lobby.mp3` | lobby |
| `dropzone.mp3` | DROPZONE rounds |
| `skydash.mp3` | SKY DASH rounds |
| `meltdown.mp3` | MELTDOWN rounds |
| `gogun.mp3` | GOGUN RUN rounds |
| `result.mp3` | result screen |

Good sources of royalty-free loops: Pixabay Music (Pixabay licence, no
attribution), OpenGameArt (filter by CC0), Kevin MacLeod / incompetech
(CC-BY 4.0 — credit required), Free Music Archive (check each licence).
